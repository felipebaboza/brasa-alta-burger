# Brasa Alta

Landing page responsiva para uma hamburgueria artesanal, feita em HTML e CSS sem dependências.

## Conteúdo

- Cardápio com seis opções e preços
- Destaques da casa
- Endereço, horários e contactos
- Links para pedido no WhatsApp e mapa

## Personalização

Substitua endereço, horários, telefone, e-mail, preços e links de pedido pelos dados reais do estabelecimento. As imagens vêm do Unsplash e as fontes do Google Fonts.

Abra `index.html` no navegador para visualizar.
